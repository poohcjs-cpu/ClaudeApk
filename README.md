# 핫딜 레이더 (안드로이드 앱)

[hotdeal-radar](https://github.com/poohcjs-cpu/hotdeal-radar) 수집기가 1시간마다 만드는 핫딜 데이터를 보여 주고, 검색하면 여러 쇼핑몰 가격을 실시간으로 비교해 주는 안드로이드 앱이에요.
커뮤니티 핫딜 글을 다나와 쇼핑몰 가격과 비교해서, **쇼핑몰 평균가보다 내 기준 이상 싼 딜**만 골라 보여 주고 알림을 보내요.

```
collector-service (이 저장소의 GitHub Actions, 1시간마다)       앱
  커뮤니티 글 수집 → 다나와 가격 비교      →     deals.json 받기 → 화면 · 알림
  → data 브랜치의 deals.json
```

수집기는 [hotdeal-radar](https://github.com/poohcjs-cpu/hotdeal-radar)의 수집기를 보완한 판이에요(`collector-service/`).
다나와 새 검색 화면 대응, 카드 조건가 제외, '원' 없는 가격·본문 가격 읽기, 막힌 출처 재시도 간격 늘리기가 들어 있어요.
`.github/workflows/collect.yml`이 1시간마다 돌려 결과를 `data` 브랜치에 올리고, 앱은
`https://raw.githubusercontent.com/poohcjs-cpu/ClaudeApk/data/deals.json`을 받아요. 받지 못하면 hotdeal-radar 웹앱의 데이터로 다시 시도해요.

앱은 사이트를 직접 긁지 않아요. 수집기가 만든 `deals.json` 한 파일만 받아요. 그래서 배터리·데이터를 거의 쓰지 않고, 사이트에 부담을 주지도 않아요.

## 설치

1. 휴대폰에서 [최신 APK](https://github.com/poohcjs-cpu/ClaudeApk/releases/download/latest/hotdeal-radar.apk)를 받아요.
2. 받은 파일을 열고, "출처를 알 수 없는 앱 설치"를 허용해요.
3. 처음 열면 알림 권한을 물어요. 허용하면 새 핫딜을 알려 드려요.

새 버전이 나오면 같은 주소에서 받아 그대로 설치하면 돼요(찜·설정은 유지돼요).

## 실시간 최저가 검색

검색 탭에서 "화장지"처럼 찾으면 **그 자리에서 다나와에 물어** 여러 쇼핑몰 가격을 비교해요.

- 다나와 검색 결과 40개 안팎에서 **가장 싼 상품**을 맨 위에 보여 줘요. 화장지·생수처럼 양이 다른 상품은 **단가**(10m당, 1L당 등)로 줄 세워요. 단가가 없는 상품은 가격순이에요.
- 상품마다 몇 개 쇼핑몰을 비교한 최저가인지 보여 주고, 누르면 **쇼핑몰별 가격**(카드 결제 조건가 제외)과 구성(1팩·2팩·3팩)별 가격·단가를 지금 읽어 보여 줘요.
- 중고·리퍼는 기본으로 빼요. 모아 둔 핫딜에 같은 제품이 있으면 "핫딜 진행 중"으로 알려 줘요.
- 검색할 때만 요청하고, 같은 검색은 10분 동안 다시 묻지 않아요. 다나와가 막으면 우회하지 않고 다나와로 바로 가는 버튼을 보여 줘요.

### 다나와 밖까지 찾기 (2026-11 후반)

목표는 "어디서 검색해도 이 앱 결과가 가장 싸다"예요. 그래서 한 번 검색할 때 여러 곳을 함께 찾아요.

- **에누리**: 다나와 다음으로 큰 가격비교 사이트도 함께 검색해요(robots.txt가 막은 /api는 쓰지 않음). 다나와에 없는 판매처, 일부 네이버 스마트스토어 판매자 가격이 들어와요.
- **공식몰 직접 검색**: 다나와·에누리에 없는 브랜드 공식몰(카페24) 특가를 찾으려고, 검색어와 관련 있는 공식몰의 검색 화면을 직접 읽어요(쇼핑몰마다 robots.txt 확인). 상품 페이지에서 '배송비 3,500원 (50,000원 이상 무료)' 규칙도 읽어요. 공식몰 목록은 기본 목록 + 수집기가 커뮤니티 딜 링크에서 알아낸 곳(`data/malls.json`) + 사용자가 공유로 알려 준 곳이에요.
- **개수만 적힌 상품의 단가 짐작**: '4+1팩'처럼 용량이 없는 공식몰 상품은 다른 판매처의 같은 상품 대부분이 한 개 950g이면 950g × 5개로 단가를 계산해 함께 비교해요.
- **지금 사도 될까?**: 수집기가 커뮤니티 딜 가격을 달별로 쌓은 기록(`data/archive/YYYY-MM.json`, 24개월 보관)에서 같은 상품의 지난 핫딜가를 찾아, 지금 최저 단가와 비교해 알려 줘요. 핫딜 알림 키워드도 바로 등록할 수 있어요.
- **링크 공유로 비교**: 광고나 다른 쇼핑몰에서 본 상품 링크를 앱으로 공유하면 그 페이지의 가격·배송비를 읽어 앱이 찾은 다른 곳과 단가로 비교하고, 카페24 쇼핑몰이면 다음 검색부터 함께 찾아요.
- **말로 검색**: '가장 싼 화장지 추천'처럼 써도 '화장지'로 찾아요. 여러 낱말로 못 찾으면 가장 긴 낱말로 다시 찾아요.
- 그래도 못 읽는 곳: 쿠팡, 네이버쇼핑 전용 상품(네이버 검색은 자동 접근 금지), robots.txt로 막은 쇼핑몰(SSG·컬리 등). 이런 곳은 버튼으로 바로 열어요.

### 2026-11 보완

- **배송비 포함 비교**(기본): 뽀로로 치약 1,540원이 배송비를 넣으면 4,540원이 되는 것처럼, 싼 생활용품일수록 배송비가 순위를 바꿔요. 단가도 배송비를 넣어 다시 계산해요. 검색 화면에서 끌 수 있어요.
- **3쪽(120개 안팎)까지 검색**: 1쪽을 먼저 보여 주고 2~3쪽을 이어서 붙여요.
- **분류 칩**: 가장 많은 분류가 절반 이상이면 처음부터 그 분류만 보여 줘요('아기 치약' → 치약만, 치약 짜개·장난감 제외).
- **쇼핑몰 개별 상품**: 가격비교로 묶이지 않은 상품도 쇼핑몰·배송비와 함께 보여 주고, 이름의 용량·개수로 단가를 계산해요.
- **카드 할인가**: '○○카드 결제 시' 값은 최저가 비교에서 빼고 참고용으로 따로 보여 줘요.
- **찜한 제품 가격 추적**: 검색에서 찜한 제품도 앱이 3시간마다 다나와 가격을 확인해 목표가 알림을 보내요.
- **관심 키워드**: 설정에 '닥터노아' 같은 말을 넣으면 그 말이 들어간 새 커뮤니티 딜을 알려 주고 핫딜 탭 위에 모아 보여 줘요.
- **커뮤니티 인기 딜**: 다나와와 비교하지 못했어도 추천·댓글이 많은 최근 24시간 글을 보여 줘요.
- **가격비교 발굴 '확인 필요'**: 한 쇼핑몰만 2위보다 25% 넘게 싸면 다른 구성·오등록일 수 있어 표시하고 TOP 5·알림에서 빼요.
- **공유로 검색**: 쇼핑몰 앱에서 상품을 '공유 → 핫딜 레이더'로 보내면 그 상품명으로 바로 최저가를 찾아요.

## 갱신 주기

**핫딜 데이터는 1시간마다** 모으고, 앱도 1시간마다 확인해요(검색은 실시간).

GitHub의 예약 실행은 몇 시간씩 건너뛰어서, 무료 예약 서비스(cron-job.org)가 1시간마다 수집을 시작하게 해요. 설정 방법: [docs/schedule-setup.md](docs/schedule-setup.md)

- 30분 예약은 너무 잦은 데다, GitHub가 실제로는 4~7시간에 한 번만 돌렸어요(41시간 동안 8번).
- 4시간은 너무 느려요. 가장 큰 출처인 뽐뿌는 RSS에 최근 15개 글만 실리는데, 저녁에는 15개가 20분 만에 채워져요. 4시간마다 읽으면 뽐뿌 글 대부분을 못 보고 지나가요. 뽐뿌는 게시판 2쪽 이후를 자동 접속에 막아 두어(403) 더 읽어 올 수도 없어요.
- 1시간마다 읽어도 붐비는 시간의 뽐뿌 글은 일부만 잡혀요. 다만 좋은 딜은 루리웹·클리앙·다모앙·아카라이브(글이 천천히 올라와 1시간이면 빠짐없이 읽음)에도 함께 올라오는 일이 많아요.

## 핫딜 기준 (기본값)

**쇼핑몰 평균가보다 10% 이상 싸고, 다른 어느 쇼핑몰보다도 싼 딜**을 핫딜로 보여 줘요. 따로 설정할 필요 없어요.

실제 수집 데이터(2026-11)로 정한 값이에요.

- 다나와에서 가장 싼 판매처는 **평소에도 나머지 판매처 평균보다 10% 안팎 싸요**(중간값 10.3%). 그래서 '평균보다 5%'는 평소 최저가 수준이라 거의 모든 제품(20개 중 18개)이 걸려요.
- 반대로 **'다른 곳 최저가보다 5%'** 싸면 정말 싼 거예요. 그래서 카드마다 "다른 곳 최저가보다 N% 쌈"을 함께 보여 줘요.
- 평균보다 17~19% 싸 보여도 다른 쇼핑몰이 같은 값에 팔면 특별한 딜이 아니라서 핫딜에서 빼요.
- 30% 이상 **역대급**, 15% 이상 **핫딜**, 그 아래는 **알뜰**로 표시해요. 알림은 15% 이상일 때만 보내요.
- 첫 버전의 기본값(30%)을 그대로 쓰던 기기는 업데이트하면 새 기본값으로 바뀌어요. 직접 바꾼 값은 그대로 둬요.

웹앱(GitHub Pages)과 같은 판정 규칙을 써요.

## 알림

- 1시간마다 `deals.json`을 받아, **아직 알리지 않은** 딜 중 알림 기준(기본 15%) 이상이고 다른 곳보다도 싼 것을 알려요.
- 가격 확인 필요(평균보다 60% 넘게 쌈)·끝난 딜·제외한 쇼핑몰은 알리지 않아요.
- 처음 켰을 때 이미 떠 있던 딜로 알림이 쏟아지지 않도록, 첫 확인은 ‘본 것’으로만 표시해요.
- 찜한 제품이 목표가 아래로 내려오면 알려요. 같은 가격으로 반복해서 알리지 않아요.
- 안드로이드 배터리 절약 때문에 몇 분~수십 분 늦을 수 있어요.

### 자동 빌드

`.github/workflows/android.yml`이 커밋마다 테스트하고 APK를 만들어요. `main`에 올리면 [latest 릴리스](https://github.com/poohcjs-cpu/ClaudeApk/releases/tag/latest)의 APK를 바꿔 끼워요.

### 서명 키

안드로이드는 **처음 설치한 앱과 같은 키로 서명된 APK만** 업데이트로 받아 줘요. 그래서 매번 같은 키로 서명해요.

- 기본: 저장소의 공용 키 `signing/shared-debug.keystore`(비밀번호 `android`). 개인용으로는 충분해요. 다만 공개 저장소라 누구나 이 키로 서명할 수 있으니, 다른 사람에게 배포할 거라면 아래처럼 개인 키를 쓰세요.
- 개인 키: 저장소 **Settings → Secrets and variables → Actions**에 `SIGNING_KEYSTORE_BASE64`(keystore 파일을 base64로), `SIGNING_STORE_PASSWORD`, `SIGNING_KEY_ALIAS`, `SIGNING_KEY_PASSWORD`를 넣으면 그 키로 서명해요. 키를 바꾸면 한 번은 앱을 지우고 다시 설치해야 해요.
