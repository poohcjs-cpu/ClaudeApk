# 핏키보드 (FitKey)

내 손가락이 **실제로 누르는 자리**를 배워서 오타를 줄이는 안드로이드 키보드 (한글 두벌식 쿼티 + 영어).
갤럭시 S23 울트라에서 쓰려고 만들었지만 안드로이드 8 이상이면 어디서나 돌아가요.

## 무엇이 다른가

- **터치 보정**: 설정 앱에서 문장 3개를 쳐 보면, 글쇠마다 내가 어느 쪽으로 얼마나 빗나가게 누르는지(치우침)와 얼마나 흩어지는지(퍼짐)를 잰다.
  이후 누른 자리가 어느 글쇠인지 정할 때 이 습관을 반영한다. 위치는 '글쇠 단위'로 배우기 때문에 키보드 높이를 바꿔도 그대로 맞는다.
- **쓰면서 계속 배우기**: 글쇠를 지우고 바로 옆 글쇠를 다시 치면 "아까 그 터치는 사실 이 글쇠였다"고 배운다. 자동으로 고친 오타를 되돌리지 않으면 그것도 배운다.
- **오타 추측**: 스페이스를 누를 때 `누른 자리들의 가능성 + 낱말이 쓰일 가능성`으로 가장 그럴듯한 낱말을 찾는다(빔 탐색).
  한글은 낱말을 글쇠 문자열(‘닭’ = `ekfr`)로 다뤄서 자모 단위 오타(ㅛ↔ㅗ, ㄱ↔ㄲ)를 고친다. 맞는 말(사전 낱말, 사전 낱말+조사, 내가 두 번 이상 쓴 말)은 건드리지 않는다.
- **되돌리기**: 자동으로 고친 직후 지우기를 누르면 원래 친 말로 돌아가고, 그 말은 다음부터 고치지 않는다.

시뮬레이션(손가락이 꽤 흔들리는 경우)에서 맞게 나온 낱말: 한국어 28% → 85%, 영어 37% → 93%, 맞게 친 말을 망친 경우 0 (`RealDictionaryTest`).

## 개인정보

- 인터넷 권한이 없다. 입력한 글은 기기 밖으로 나갈 수 없다.
- 배운 터치 습관·내 낱말은 앱 전용 폴더에만 저장하고 백업에서도 뺀다. 설정에서 모두 지울 수 있다.
- 비밀번호 칸·'학습 금지' 칸에서는 추천·고치기·배우기를 하지 않는다.

## 구조

```
engine/Hangul.kt        두벌식 조합 (겹받침·겹모음·받침 넘기기, 자모 단위 지우기)
engine/Layout.kt        자판 배열과 글쇠 위치 (글쇠 단위)
engine/TouchModel.kt    글쇠별 치우침·퍼짐 학습, 누른 자리 판정
engine/Dictionary.kt    글쇠 문자열로 정렬한 사전, 내 낱말
engine/Decoder.kt       오타 추측 (빔 탐색), 자동 고치기 판단
engine/InputEngine.kt   글쇠 → 글, 추천 막대, 되돌리기, 배우기 (안드로이드와 떨어져 있어 단위 시험 가능)
ime/FitKeyService.kt    안드로이드 키보드 서비스
ime/KeyboardView.kt     키보드 화면 (직접 그림)
ui/MainActivity.kt      설치 안내·설정·터치 보정
```

```bash
./gradlew testDebugUnitTest assembleRelease
./gradlew testDebugUnitTest -Pscreenshots   # 화면 그림: app/build/screenshots
```
